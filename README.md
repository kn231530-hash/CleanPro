# CleanPro

A responsive, Google-inspired CleanPro landing page built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser.

## Deploy on Vercel
1. Open Vercel and choose **Add New → Project**.
2. Import `kn231530-hash/CleanPro` from GitHub.
3. For this static HTML project, no build command is needed. Set the output directory to the repository root (or leave the default if Vercel detects it).
4. Deploy.

If your existing `clean-pro-gilt.vercel.app` project is connected to a different repository, this commit will not change that live site until you connect this repository to the Vercel project or deploy it as a new project.

## Important
The booking form is currently a front-end demo. It does not send or save customer data. Connect a backend or booking provider before accepting real requests.
